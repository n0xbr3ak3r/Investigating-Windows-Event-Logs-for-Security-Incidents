# Windows Event Logs Investigation

Mini-projet pratique d'investigation des journaux d'événements Windows dans le cadre de ma formation en cybersécurité.

## Description

Ce laboratoire consiste à analyser les **Windows Security Event Logs** afin d'identifier et d'étudier des tentatives d'authentification suspectes.

L'investigation s'appuie notamment sur :

* **Windows Event Viewer**
* **Microsoft Log Parser**
* **PowerShell**
* **Event ID 4625** — échec d'authentification
* **Event ID 4624** — authentification réussie
* La corrélation temporelle des événements

L'objectif est de comprendre comment exploiter les journaux Windows dans le cadre d'une investigation de sécurité et d'identifier des scénarios potentiellement liés à une attaque par force brute ou par dictionnaire.

## Environnement

* Windows 11
* VMware Workstation Player
* PowerShell
* Microsoft Log Parser
